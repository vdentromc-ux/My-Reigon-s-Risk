Most common natural disasters:
--------------------
wildfire
flood
winter storms
--------------------
extreme heat





## Must-have:

A region search input (city or "use my location")
A fetch from at least one disaster API showing recent events
A map (Leaflet) with pinned events
A top-3 risks list for the region
An AI-generated preparedness checklist tailored to those risks
A clear empty / loading / error state
A save/share button


## Nice-to-have:

A second API (active alerts on top of historical events)
A time-machine slider that animates events over years
A "kit built" checkbox per item, saved in localStorage
A class/household preparedness tracker
A confidence label on the AI explanation


## Out of scope:

Real user accounts and login
A backend database
Push notifications for new alerts
Multi-language support
